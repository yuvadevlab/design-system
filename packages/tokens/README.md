# @yuva-devlab/tokens

Design tokens, color themes, and Tailwind CSS 4 preset bridge for the Yuva DevLab ecosystem.

## Installation

```bash
pnpm add @yuva-devlab/tokens
```

## Usage

### Tailwind CSS 4 Preset

In your root stylesheet:

```css
@import "tailwindcss";
@import "@yuva-devlab/tokens/preset.css";
@import "@yuva-devlab/tokens/themes/orchestrai.css";
```
